Drop screenshots in this folder (png, jpg, webp, gif or avif).

The file name becomes the title: `stripe-checkout-page.png` shows as "Stripe Checkout Page".

For notes, tags and a source link, add a Markdown file with the same name next to it:

    stripe-checkout-page.md

    ---
    title: Stripe checkout
    tags: [Forms, Payments]
    source: https://example.com/where-i-found-it
    ---
    The error messages appear inline and never shift the layout.

Files starting with an underscore are ignored.
