## Why this is interesting

Checking homework answers is easy. Seeing which step went wrong is not. A tool that shows every step of nodal and mesh analysis would help while studying.

## Scope

- Enter a netlist or draw simple resistor and source circuits
- Solve with a symbolic or numeric solver
- Print the equations the way a textbook would

## Roadmap

- [ ] Netlist in, node voltages out
- [ ] Show the KCL equation for each node
- [ ] Mesh analysis
- [ ] Drawing canvas
